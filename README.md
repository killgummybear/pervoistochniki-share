# Превью ссылок на pervoistochniki.ru для соцсетей

Сервер курса стоит в России, и роботы Facebook и LinkedIn до него не достают: превью ссылок в этих соцсетях пустое.
Здесь лежат страницы с тегами превью и обложкой — роботы читают их с GitHub Pages, а человек сразу переходит
на основной сайт (с метками utm_source по соцсети, если их нет в ссылке).

В соцсетях ставьте ссылки вида `https://share.pervoistochniki.ru/` (главная) или `https://share.pervoistochniki.ru/cmo`
(и так для каждой страницы витрины). Тексты тегов взяты со страниц витрины; поменяли их на сайте — обновите и здесь.
